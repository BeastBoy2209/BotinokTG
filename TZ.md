# Техническое задание (ТЗ) на разработку Telegram-бота

## Описание проекта
Telegram-бот для автоматизации рутинных задач в групповых чатах: скачивание медиа, ведение общих счетов, случайный выбор пользователей и массовые упоминания.

## Стек технологий
- Язык: Go
- База данных: PostgreSQL
- Библиотека Telegram: github.com/go-telegram/bot
- Внешние зависимости: yt-dlp, ffmpeg

## Функциональные требования

### 1. Архитектура и база данных
- [x] Настроить подключение к PostgreSQL.
- [x] Настроить миграции (golang-migrate).
- [x] Реализовать Graceful Shutdown.
- [x] Таблица `users` (внутренний ID, Telegram ID, имя, username).
- [x] Таблица `chats` (внутренний ID, Telegram ID).
- [x] Таблица `chat_members` (связь пользователей и чатов).
- [x] Фоновая регистрация пользователей и чатов через Middleware.

### 2. Загрузка видео
- [x] Регулярные выражения для распознавания ссылок (YouTube, TikTok, Instagram, Twitter, Pinterest).
- [x] Интеграция yt-dlp для загрузки видео.
- [x] Интеграция API tikwm.com для загрузки TikTok без водяных знаков.
- [x] Принудительное конвертирование видео в H.264 (для корректного воспроизведения в Telegram).
- [x] Асинхронная загрузка с отправкой сообщения "Скачиваю...".
- [x] Механизм Retry (до 3 попыток) при ошибках отправки видео.

### 3. Управление расходами (Счета/Долги)
- [x] CRUD операций для счетов (создание, закрытие).
- [x] Добавление участников к счету по тегам (например: `@user`).
- [x] Добавление расходов пользователями в конкретный счет.
- [x] Просмотр списка активных счетов (`/event list`).
- [x] Просмотр истории закрытых счетов (`/event history`).
- [x] Просмотр информации по счету (`/event info`).
- [x] Алгоритм расчета долгов (кто кому сколько должен, минимизация транзакций) (`/event debts`).

### 4. Утилиты для чата
- [x] Выбор случайного участника чата из базы БД (`/who`).
- [x] Выбор случайного участника из переданных аргументов (`/who @user1 @user2`).
- [x] Массовое упоминание всех активных пользователей чата (`@all`, `@все`, `!all`, `!все`).
